# 🔧 TROUBLESHOOTING

## LDPlayer does not start

Check:

* Hardware virtualization
* RAM availability
* Free disk space
* Graphics drivers
* Windows compatibility
* Antivirus/security software
* Emulator installation files

---

## Emulator is slow

Try:

1. Close unnecessary applications.
2. Check CPU usage.
3. Check available RAM.
4. Update your graphics driver.
5. Make sure virtualization is enabled.
6. Adjust CPU/RAM allocation inside LDPlayer.
7. Reduce Android graphics settings.

LDPlayer notes that emulator performance depends heavily on the resources allocated to the emulator.

---

## Application says "Device isn't compatible"

LDPlayer explains that compatibility can depend on the Android version, 32-bit/64-bit requirements, and application developer restrictions.

For LDPlayer 4 specifically, remember that it uses Android 7.1.2, so newer applications requiring a newer Android version may not work.
